Cursor 編輯器高效開發實戰指南

探索 Cursor 的三大核心能力：Cmd+K 行內編輯、Composer 全局跨檔案程式碼生成，以及如何善用 .cursorrules 配置開發規則。

本文目錄

  • 1. Cmd + K 行內 Prompt 指令
  • 2. Composer 多檔案協同修改
  • 3. 設定 AGENTS.md / .cursorrules

1. Cmd + K 行內 Prompt 指令

在 Cursor 中，最常用的快捷鍵莫過於 Cmd + K（Windows 上為 Ctrl + K）。你可以圈選特定程式碼後按下的該快捷鍵，直接對 AI 下達修改或重構指令。

// 選取範例並輸入提示詞："請幫我加上 try-catch 錯誤處理與詳細註解"

2. Composer 多檔案協同修改

當需要修改的範疇跨越多個檔案時（例如新增 API 並且需更新前端調用介面），可以使用 Cmd + I 開啟 Composer。

3. 設定 AGENTS.md / .cursorrules

透過在專案根目錄放置 `AGENTS.md`，可以讓 AI 在生成程式碼時主動遵照規範（如 Tailwind 樣式設計、命名規範），減少手動微調的時間。

重點總結 (Key Takeaways)

  • 單一函式重構使用 Cmd + K 最靈活。
  • 跨檔案新功能開發使用 Composer。
  • 建立 AGENTS.md 確保 AI 產出的程式碼風格一致。
