GitHub Pages 部署教學：三分鐘公開你的靜態網站

從建立 Repository、推送程式碼到開啟 Pages，一步一步讓網站上線。

本文目錄

  • 1. 事前準備
  • 2. 推送程式碼
  • 3. 開啟 GitHub Pages
  • 4. 本機預覽

1. 事前準備

本專案是純靜態網站（HTML + CSS + JS），不需要建置流程，因此可以直接用 GitHub Pages 發佈。請先確認已安裝 Git 並擁有 GitHub 帳號。

2. 推送程式碼

在專案根目錄執行：

git init
git add .
git commit -m "init: AI Developer Docs"
git branch -M main
git remote add origin https://github.com/<你的帳號>/<repo 名稱>.git
git push -u origin main

3. 開啟 GitHub Pages

進入 Repository 的 Settings → Pages，Source 選擇 Deploy from a branch，Branch 選 main 與 / (root)，按下 Save。約一至兩分鐘後即可在 https://<帳號>.github.io/<repo>/ 瀏覽。

4. 本機預覽

部署前可在本機啟動簡易伺服器預覽：

python -m http.server 8000
# 瀏覽 http://localhost:8000

重點總結 (Key Takeaways)

  • 純靜態網站可直接用 GitHub Pages 發佈。
  • 使用相對路徑，網站放在子路徑下也能正常運作。
  • 推送到 main 之後，Pages 會自動更新。
