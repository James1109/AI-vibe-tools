Prompt 工程基礎指南

學習如何精確撰寫提示詞：角色、任務、限制與輸出格式，發揮 LLM 的最大潛能。

本文目錄

  • 1. 為什麼提示詞很重要
  • 2. 四要素公式
  • 3. 範例對照
  • 4. 進階技巧

1. 為什麼提示詞很重要

LLM 會根據你給的上下文推測意圖。提示越模糊，結果越不穩定；提示越具體，輸出越接近預期。Prompt 工程的核心就是「把需求講清楚」。

2. 四要素公式

一個好的提示詞通常包含四個部分：

  • 角色 (Role)：你希望 AI 扮演誰。
  • 任務 (Task)：要完成的具體事項。
  • 限制 (Constraints)：字數、風格、禁止事項。
  • 輸出格式 (Format)：表格、條列、JSON 或 HTML。

3. 範例對照

模糊的提示：

幫我寫一個網頁

具體的提示：

你是資深前端工程師。請用 Tailwind CSS 做一個暗色系個人作品集首頁，
包含 Hero、作品卡片三張與 Footer，輸出為單一 index.html。

4. 進階技巧

提供範例（Few-shot）、要求逐步思考、先列大綱再展開，以及把長規則寫進專案層級的 AGENTS.md，避免每次重複貼上。

重點總結 (Key Takeaways)

  • 提示詞 = 角色 + 任務 + 限制 + 輸出格式。
  • 範例與具體條件能大幅提升穩定度。
  • 重複使用的規則應寫進 AGENTS.md，而不是每次手打。
